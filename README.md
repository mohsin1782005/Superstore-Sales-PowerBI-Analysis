# Executive Sales & Profit Dashboard (Superstore Analysis)
A professional E-commerce Sales &amp; Profit Dashboard built with Power BI, featuring custom DAX measures, Time Intelligence, and advanced UI/UX design.

## 📊 Project Overview
This project transforms raw E-commerce data into an interactive executive-level dashboard. It highlights key performance indicators (KPIs) to help stakeholders make data-driven decisions regarding sales trends and profitability.

## 🛠️ Technical Stack
* **Tool:** Power BI Desktop
* **Data Modeling:** Star Schema with a custom Calendar Table.
* **Languages:** DAX (Data Analysis Expressions) for complex measures.
* **Design:** Custom Dark Mode UI with high-contrast accent colors.

## 💡 Key Features & Logic
* **Time Intelligence:** Created DAX measures for Year-over-Year (YoY) Sales Growth.
* **Dynamic UI:** Implemented "Top N" product filtering and interactive tooltips.
* **Data Architecture:** Established one-to-many relationships between the Sales fact table and the Calendar dimension.
